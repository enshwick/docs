Це те, що я хотів би додати в Enshwick далі. Жодна з цих цілей не має дати.
До версії 1.0 будь-яка з них може змінитися.

## Чи працюватимуть моди між версіями?

Від версії 1.0 я хотів би, щоб зв’язок між Enshwick і модом лише розширювався.
Тоді мод, зібраний під старішу версію 1.x, і далі завантажуватиметься без
перезбирання.

До 1.0 між альфа-версіями може змінитися будь-що. Перед оновленням зробіть
копію збережень.

## Чи матимуть тексти модів форми множини?

Я планую додати в тексти модів форми множини за правилами Unicode CLDR. Кожна
мова отримає свої форми для одного, кількох і багатьох, тож рядок на кшталт
«3 предмети» буде написано правильно.

## Чи буде цей сайт іншими мовами?

Я хотів би, щоб цей сайт був не лише англійською й українською.

## Чи будуть моди лише для одного гравця?

Було б добре мати моди, що працюють лише в грі одного гравця. Зараз
мод працює на сервері або на сервері й у грі кожного гравця. Для модів одного
гравця треба було б переглянути, як працюють ці сторони.

## Як допомогти?

Щоб попросити API або поділитися ідеєю,
[відкрийте звернення](https://github.com/enshwick/enshwick/issues/new?template=api-request.yml)
на GitHub. Pull request’и теж вітаються, а
[посібник для учасників](https://github.com/enshwick/enshwick/blob/main/CONTRIBUTING.md)
пояснює, як вони працюють. Сторінка
[покриття API](/uk/dev/api-coverage/) показує, що API охоплює зараз.
