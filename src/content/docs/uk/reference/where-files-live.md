Enshwick тримає файли у двох місцях. Те, що належить установці, лежить у теці
гри. Те, що належить одному світу, лежить поруч зі збереженням цього світу.

## У теці гри

Тека гри — це тека, де лежить `enshrouded.exe` або `enshrouded_server.exe`.

| Шлях                                          | Що там                                                                          |
| --------------------------------------------- | ------------------------------------------------------------------------------- |
| `powrprof.dll`                                | файл, що запускає Enshwick разом із грою                                        |
| `mods/enshwick/`                              | сам Enshwick, `enshwick.dll`, і файли, які він тримає для цієї установки        |
| `mods/<ідентифікатор мода>/`                  | по теці на мод, з файлами мода; мод працює, поки його тека на місці             |
| `mods/<ідентифікатор мода>/hold.txt`          | утримання, яке поставив мод: гра зупиняється, поки мод не працює                |
| `enshwick.toml`                               | налаштування самого Enshwick, наприклад скільки писати в журнали                |
| `mod-controls.toml`                           | клавіші, які ви обрали для керування модами на цьому комп'ютері, лише змінені   |
| `export/<ідентифікатор мода>/`                | файли, які мод типово записує для інших інструментів, як-от вікі чи мапи        |
| `logs/enshwick_<дата>_<час>.log`              | рядки самого Enshwick за один запуск: які моди завантажилися і чому якийсь ні   |
| `logs/<ідентифікатор мода>_<дата>_<час>.log`  | рядки одного мода за один запуск                                                |
| `logs/enshwick-crash_<дата>_<час>.log`        | один збій, з модом, Enshwick або грою, звідки він стався                        |
| `logs/start.log`                              | чому Enshwick не запустився; файл є лише тоді, коли Enshwick не запустився      |

У `mods/enshwick/` також лежать `clones.toml`, предмети й об'єкти, які моди
скопіювали з ігрових, і `kept-stacks.toml`, розміри стосів, з якими зберегли
світ. Не видаляйте ці файли.

## Поруч із кожним збереженням

Гра тримає кожен світ у файлі на кшталт `world0.ksd`. Ця назва — слот, `world0`,
`world1` і так далі, а не назва світу. Enshwick тримає дві теки поруч зі
збереженням кожного світу, названі за цим файлом:

| Шлях                                        | Що там                                                                                                                                             |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `world0-mod-settings/<ідентифікатор мода>/` | налаштування мода для цього світу                                                                                                                  |
| `world0-mod-settings/enshwick/`             | правила Enshwick для світу: чи потрібні гравцям його моди, щоб лишитися, у `enshwick.toml`, і рецепти, які тут ніхто не крафтить, у `recipes.toml` |
| `world0-mod-data/<ідентифікатор мода>/`     | те, що мод тримає для світу, наприклад чия яка скриня Safe                                                                                         |
| `world0-mod-data/enshwick/`                 | те, що Enshwick тримає для світу, наприклад моди, з якими світ працював, у `mods.lock`                                                             |

[Резервна копія світів](/uk/guides/back-up-saves/) пояснює, де гра тримає
збереження. Копіюйте збереження разом із двома теками, і світ збереже все, що
знають про нього моди.

Steam Cloud не копіює ці дві теки на інші ваші комп'ютери. [Резервна копія
світів](/uk/guides/back-up-saves/) пояснює, як їх перенести.

## Коли новий світ отримує стару назву

Коли ви видаляєте світ у грі, гра лишає його дві теки. Наступний новий світ
отримує ту саму назву, наприклад `world2.ksd`.

Enshwick бачить, що теки належать старому світу. Він перейменовує їх, наприклад
на `world2-mod-data.old-2026-11-02-14-30-00`. Новий світ починає з типових
налаштувань кожного мода.

Нічого не видаляється. Видаліть перейменовані теки, коли вони вам більше не
потрібні.

Щоб почати світ спочатку, видаліть його збереження і дві його теки.

## Журнали й резервні копії

Кожен запуск пише нові файли журналів, названі за часом, коли він почався,
наприклад `enshwick_2026-11-03_10-00-00.log`. Enshwick тримає 10 найновіших
файлів самого Enshwick, кожного мода і збоїв, а старіші видаляє. Ви можете
видалити будь-який файл журналу самі.

Файл журналу вміщує до 8 МіБ. Повний файл закінчується рядком, що називає
наступний файл, і запуск пише далі туди.

Щоб попросити допомоги, додайте файл Enshwick за запуск, що пішов не так.
Коли не так пішов мод, додайте ще файл цього мода. Після збою додайте файл
збою.

Коли Enshwick не запустився, власного файлу в нього немає. Тоді додайте
`logs/start.log`.

Коли Enshwick знову записує свій файл, він лишає старий поруч, наприклад
`clones.toml.bak`.

Ідентифікатор мода дає назви його текам, наприклад `enshwick.game-rates`.
Сторінка кожного мода показує його ідентифікатор.
