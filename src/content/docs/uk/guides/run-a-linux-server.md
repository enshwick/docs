Виділений сервер Enshrouded існує лише для Windows. На Linux він працює під
Proton. Налаштування на цій сторінці прибирають більшу частину часу, який додає
Proton.

## Встановіть сервер з Enshwick

1. Встановіть виділений сервер через SteamCMD, застосунок `2278520`.
2. [Встановіть Enshwick](/uk/guides/install/) у теку, де лежить
   `enshrouded_server.exe`.
3. Запускайте сервер через Proton із `WINEDLLOVERRIDES="powrprof=n,b"` у змінних
   середовища. Тоді Proton бере `powrprof.dll` від Enshwick.

## Візьміть ядро з ntsync

Запускайте Linux 6.14 або новіший із завантаженим модулем `ntsync`. Proton 11 і
GE-Proton 11 користуються ним без додаткових налаштувань. З ним очікування між
потоками гри займають значно менше часу.

1. Завантажте модуль: `sudo modprobe ntsync`.
2. Перевірте, що існує `/dev/ntsync`.
3. У контейнері передайте пристрій усередину, наприклад `--device /dev/ntsync`
   для Docker.

## Вимкніть налагоджувальний вивід Wine

Задайте `WINEDEBUG=-all` у змінних середовища сервера. Тоді Wine не пише
налагоджувальних рядків. Ці рядки забирають час на завантаженому сервері.

## Закріпіть сервер за ядрами

Дайте серверу власні ядра процесора, щоб інші програми не пересували його між
ядрами.

- Із systemd задайте `CPUAffinity=` у юніті служби.
- У Docker використайте `--cpuset-cpus`.
- Без них запускайте сервер через `taskset -c <ядра>`.

`WINE_CPU_TOPOLOGY` задає, які ядра бачить гра. Використайте його, коли гра має
бачити менше ядер, ніж є на хості.

## Дайте процесору працювати на повній частоті

Поставте регулятор частоти процесора `performance`, щоб ядра не сповільнювалися
між періодами навантаження: `sudo cpupower frequency-set -g performance`.

## Перевірте результат

Мод [Optimizer](/uk/mods/optimizer/) під час запуску пише один рядок у
`logs/enshwick/mods/enshwick.optimizer.log`. У рядку версія Wine, ядро, знайдені
швидкі очікування, регулятор частоти і процесори, які побачила гра. З ntsync там
буде `/dev/ntsync present`. Для кожного налаштування, якого бракує, мод додає
пораду.
