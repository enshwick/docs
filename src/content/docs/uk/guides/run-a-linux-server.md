Виділений сервер Enshrouded існує лише для Windows, тож на Linux він працює
під Proton. Ці налаштування прибирають більшу частину часу, який додає Proton.

## Встановіть сервер з enshwick

1. Встановіть виділений сервер через SteamCMD, застосунок `2278520`.
2. [Встановіть enshwick](/uk/guides/install/) у теку, де лежить
   `enshrouded_server.exe`.
3. Запускайте сервер через Proton із `WINEDLLOVERRIDES="powrprof=n,b"` у
   змінних середовища, щоб Proton брав `powrprof.dll` від enshwick.

## Візьміть ядро з ntsync

Запускайте Linux 6.14 або новіший із завантаженим модулем `ntsync`. Proton 11
і GE-Proton 11 користуються ним самі. З ним очікування між потоками гри
стають значно дешевшими.

1. Завантажте модуль: `sudo modprobe ntsync`.
2. Перевірте, що існує `/dev/ntsync`.
3. У контейнері передайте пристрій усередину, наприклад `--device /dev/ntsync`
   для Docker.

## Вимкніть налагоджувальний вивід Wine

Задайте `WINEDEBUG=-all` у змінних середовища сервера. Тоді Wine не пише
налагоджувальних рядків, які забирають час на завантаженому сервері.

## Закріпіть сервер за ядрами

Дайте серверу власні ядра процесора, щоб інша робота його не пересувала.

- Із systemd задайте `CPUAffinity=` у юніті служби.
- У Docker використайте `--cpuset-cpus`.
- Без них запускайте сервер через `taskset -c <ядра>`.

`WINE_CPU_TOPOLOGY` каже Proton, які ядра бачить гра, коли треба показати їй
менше, ніж є на хості.

## Дайте процесору працювати на повній частоті

Поставте регулятор частоти процесора `performance`, щоб ядра не сповільнювалися
між сплесками роботи: `sudo cpupower frequency-set -g performance`.

## Перевірте результат

Мод Optimizer під час запуску пише один рядок у
`logs/enshwick/mods/optimizer.log`: версію Wine, ядро, знайдені швидкі
очікування, регулятор частоти і скільки процесорів побачила гра. З ntsync там
буде `/dev/ntsync present`. Для кожного налаштування, якого бракує, мод додає
пораду.

Про сервер у Docker або Kubernetes читайте [Running a server in Docker or
Kubernetes](/uk/dev/servers/).
