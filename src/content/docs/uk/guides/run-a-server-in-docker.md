Виділений сервер у контейнері отримує Enshwick із файлів поруч з
`enshrouded_server.exe`. Сам ніхто їх не встановить. Образ або том несе їх у
тих версіях, які ви обрали.

## Покладіть файли в образ

Покладіть `powrprof.dll` і теку `mods` в образ поруч із сервером. Підійде й
том, змонтований туди.

- `enshwick.zip` містить Enshwick і жодного мода. Кожен мод має власний архів у
  випусках свого проєкту.
- До першого випуску, 1.0.0, ці файли існують лише як збірки для розробки,
  наприклад
  `https://github.com/enshwick/enshwick/releases/download/dev/enshwick.zip`.
  Кожна нова збірка замінює цей файл.
- Завантажте файли один раз і зберігайте їх у власному сховищі, наприклад у
  бакеті або в контексті збирання образу. Тоді кожне перезбирання образу бере ті
  самі файли.
- Закріпіть кожен архів за його SHA-256. GitHub показує його поруч із кожним
  файлом випуску. Тоді образ містить саме той файл, який ви перевірили.

Цей шаблон бере архів із контексту збирання. Кожне `<...>` задайте самі:

```dockerfile
FROM alpine:<version> AS enshwick
RUN apk add --no-cache unzip
ARG ENSHWICK_SHA256=<the archive's SHA-256>
WORKDIR /enshwick
COPY enshwick.zip ./
RUN echo "$ENSHWICK_SHA256  enshwick.zip" | sha256sum -c - \
 && unzip -q enshwick.zip -d files

FROM <your Enshrouded server image>
COPY --from=enshwick /enshwick/files/ <folder that holds enshrouded_server.exe>/
```

Моди інших авторів проходять ті самі кроки з власними посиланнями на випуски.

## Змінюйте версії викочуванням

Нова версія — це новий образ або новий том. Викочуйте його, як будь-яку іншу
зміну. Ніколи не змінюйте файли в запущеному контейнері: наступний перезапуск
візьме набір, якого ніхто не збирав, і репліки розійдуться.

## Тримайте сервер робочим після оновлення гри

Після оновлення гри Enshwick може не мати таблиці для нової збірки гри. Тоді він
шукає потрібне за шаблонами коду, і вимикається лише те, чого шаблони не
знайшли. З `build_patterns = false` у `mod-configs/enshwick.toml` така збірка
натомість працює без модів.

Enshwick зберігає знайдене шаблонами в `mod-data/enshwick/carried-server.txt`.
Він читає цей файл, поки гра і Enshwick ті самі, тож шукати доведеться лише під
час першого запуску після оновлення. Тримайте `mod-data` на томі, щоб зберегти цей файл.

Перезберіть образ, коли новіший Enshwick матиме таблицю для цієї збірки.

## Перенесіть світ в іншу теку

Моди зберігають дані кожного світу в `mod-data/<mod id>/worlds/<key>/`. Ключ
містить геш теки збереження, наприклад `world0-1a2b3c4d`. Світ, чиє збереження
переїхало в іншу теку, отримує новий ключ. Так буває зі світом, який ви
перенесли з гри на виділений сервер.

Enshwick сам знаходить старі дані. Світ може завантажитися зі збереженням, але
без даних модів під своїм ключем. Коли рівно один інший ключ із тією самою
назвою збереження має дані, Enshwick забирає ці дані собі.

Enshwick переносить теки, коли старого збереження вже немає. Він копіює їх, коли
старе збереження ще лежить на місці. Журнал каже, що саме він зробив.

Коли дані мають два або більше ключів із тією самою назвою збереження, Enshwick
нічого не переносить. Журнал і підсумок стану перелічують ці ключі. Зупиніть
сервер і перейменуйте потрібну теку в кожній `mod-data/<mod id>/worlds/` на
новий ключ.

Журнал називає новий ключ у рядку на зразок `world key <key>, from <path>`.

## Перевірте, що завантажив сервер

На кожному запуску Enshwick пише `mods/enshwick/enshwick.lock`. Там версія і
SHA-256 Enshwick та збірка гри. Там також ідентифікатор, версія, файл і SHA-256
кожного запущеного мода.

Порівняйте цей файл із lock-файлом сервера, якому ви довіряєте, або з гешами
файлів, які ви поклали. Тоді ви знаєте, що под запускає саме той образ, який ви
задумали.

## Привітайте гравців, коли вони заходять

Задайте `motd` у `mod-configs/enshwick.toml`, повідомлення дня. Кожен гравець
бачить його в чаті, коли заходить:

```toml
motd = """
Welcome to Ember Vale.
Restarts at 06:00 UTC. Rules: discord.gg/example
"""
```

Повідомлення — це звичайний текст. Enshwick лишає перші 4 рядки і 500 байтів,
а порожні рядки й керівні символи прибирає. Журнал попереджає, коли Enshwick
обрізає текст.

Зміна діє з наступного входу гравця, без перезапуску.

## Беріть моди з Nexus

Завантаження з Nexus потребують входу, а його API — облікового запису Premium.
Тож жодне автоматичне збирання чи сервер не завантажить їх сам. Завантажте такий
мод один раз власноруч, зберігайте файл у своєму сховищі й кладіть в образ
звідти, за версією.

## Запустіть сервер на хості Linux

Образ на Linux запускає сервер для Windows під Proton. Беріть GE-Proton або
Proton від Valve, закріплений за версією і запущений поза Steam. Звичайний Wine
теж підійде, але Proton першим отримує виправлення, потрібні іграм.

[Сервер на Linux](/uk/guides/run-a-linux-server/) показує налаштування, як-от
`WINEDLLOVERRIDES`. З обмеженням процесора для контейнера
[Optimizer](/uk/mods/optimizer/) запускає не більше робочих потоків, ніж
дозволяє обмеження.
