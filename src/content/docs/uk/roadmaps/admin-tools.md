Admin Tools допомагає адміністраторам сервера керувати ним.

Це те, що я хотів би додати в Admin Tools після Enshwick 1.0. Жодна з цих цілей
не має дати. Будь-яка з них може змінитися.

## Чи писатиме Admin Tools у Discord?

Я хотів би, щоб Admin Tools писав у канал Discord, що відбувається на сервері.
Це можуть бути гравці, що заходять або виходять, оголошення, вигнання й бани.

## Чи зможуть інші програми керувати сервером?

Я хотів би, щоб Admin Tools через інтернет відповідав на запити інших програм,
наприклад панелі сервера чи бота. Така програма могла б дізнатися, хто онлайн.
Вона також могла б виконувати дії, які адміністратор виконує в грі.

## Чи покаже сервер свою мапу в браузері?

Я хотів би, щоб Admin Tools показував мапу світу як вебсторінку. На сторінці
могло б бути видно, де гравці.

## Як допомогти?

Щоб поділитися ідеєю для Admin Tools,
[відкрийте звернення](https://github.com/enshwick/mods/issues/new/choose) в
репозиторії модів на GitHub. Сторінка [Що буде далі](/uk/aims/) перелічує цілі
самого Enshwick.
