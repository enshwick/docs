## Can Enshwick run beside another mod loader?

No. Enshwick does not support another mod loader in the same game folder.

If the game misbehaves or does not start while another loader is installed,
remove that loader.

Another loader may change a part of the game that an Enshwick feature needs.
Then Enshwick turns off only that feature and leaves the other change in place.
The log, the **Mods** screen and a chat line when you join name the file that
made the change.
