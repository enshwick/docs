## What happens after a game update?

You do not need a new Enshwick after a game update.
A server can choose to run a new build without mods instead, as [Run a server in Docker or Kubernetes](/guides/run-a-server-in-docker/) shows.

When the game starts, Enshwick looks for the parts of the game its features need.
If a part changed, Enshwick turns off only the features that need it.
Everything else keeps working.

The chat and the Mods screen name each feature that is off.

## Does Enshwick support another mod loader?

No. Enshwick does not support another mod loader in the same game folder.

If the game misbehaves or does not start while another loader is installed,
remove that loader. Some loaders change the game's data files. If the problem
stays, verify the game files in Steam.

When Enshwick starts, it checks the parts of the game its features need. If
another program already changed one, Enshwick turns off only the features on
that part and leaves the change in place. The log names the file that made the
change when Enshwick can tell which one.

Enshwick does not check changes made after it starts.
