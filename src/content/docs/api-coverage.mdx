Each row is one area of the game. Open it to see what a mod can do there, and
which API items do it. The
[API source](https://github.com/enshwick/enshwick/tree/main/crates/enshwick/src)

## What does each capability mean?

| Capability | What a mod can do                                    |
| ---------- | ---------------------------------------------------- |
| Read       | see the current state                                |
| Change     | change values and rules of the game                  |
| Create     | add something of its own, such as an item or recipe |
| Events     | hear what happened                                   |
| Interface  | show it to a player and let the player act on it     |

## What does each state mean?

| State          | Meaning                                         |
| -------------- | ----------------------------------------------- |
| Covered        | the API has calls for it                        |
| In work        | the API for it is being built                   |
| Researching    | the needed facts about the game are being found |
| Not supported  | the API does not offer it                       |
| Does not apply | the game has nothing of this kind in that area  |

A covered row is Stable or Unstable, as [Stability](/dev/stability/) lists its
items. A stable row marks each unstable item it names. An unstable item needs
the `unstable` feature and may change in any release.
