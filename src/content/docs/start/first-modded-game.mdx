In about ten minutes, you install Enshwick, start Enshrouded with it and see a
mod change your world. You need Enshrouded from Steam and a program that opens
ZIP files, such as Windows Explorer.

The first mod is [Game Rates](/mods/game-rates/). With it, building recipes
give twice as many pieces for the same cost. You see this in the crafting menu
within a minute.

## Get the files

You need two archives. One holds Enshwick, the modding API and the loader that
runs mods. The other holds Game Rates.

<Steps>

1. Download [enshwick.zip](https://github.com/enshwick/enshwick/releases/download/dev/enshwick.zip) and
   [enshwick-game-rates.zip](https://github.com/enshwick/mods/releases/download/dev/enshwick-game-rates.zip). Your browser saves them to your
   Downloads folder.

2. Open Steam and go to your library.

3. Right-click Enshrouded, then select **Manage** and **Browse local files**.
   A window opens on the game folder, the one that holds `enshrouded.exe`.

4. Open each archive and copy everything in it into the game folder.
   The game folder now holds the file `powrprof.dll` and the folder `mods`.

</Steps>

## Add a launch option on Linux

<Tabs syncKey="os">
<TabItem label="Windows">

Nothing more to do. Windows starts Enshwick with the game.

</TabItem>
<TabItem label="Linux and Steam Deck">

<Steps>

1. In Steam, right-click Enshrouded and select **Properties**.

2. Paste this line into **Launch options**:

   ```text
   WINEDLLOVERRIDES="powrprof=n,b" %command%
   ```

</Steps>

Proton now loads `powrprof.dll` from the game folder. This file starts
Enshwick.

</TabItem>
</Tabs>

## Start the game

<Steps>

1. Start Enshrouded from Steam as usual.

2. Wait for the main menu. It now has a **Mods** entry.

3. Select **Mods**. The list shows every mod that loaded: here, Game Rates.

</Steps>

If the list is empty or **Mods** is missing, the log says why.
[Where files live](/reference/where-files-live/) shows where the log is.

## See the mod work

<Steps>

1. Load a world you play, or start a new one.

2. Open the crafting menu at a workbench. Find a building block recipe, such
   as a wall.

3. Look at how many pieces it makes. Game Rates doubles this number by
   default.

</Steps>

Your first mod works. Every other mod is added the same way: download its
archive from its page and extract it into the game folder.
