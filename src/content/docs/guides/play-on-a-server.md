To join a server that runs mods, install the same Enshwick build as the server.
Then join as usual. The server checks your mods when you join.

1. Ask the server's owner which Enshwick build it runs. If you join with another
   build, the game names the mod and version you need.
2. [Install Enshwick](/guides/install/), or [update it](/guides/update/) to
   match the server.
3. Join the server from the game's menu.

## What the server checks

Some mods change things that the server and every player must agree on, such as
recipes. Each mod's page says whether it is one of those.

- If you do not have such a mod, or have another version, the game tells you
  which one. You do not join.
- If you have such a mod and the server does not run it, the mod stays off while
  you play there. The game tells you so.
- Other mods are your own choice. They run as usual.

## Settings on a server

The server's settings apply while you play there. When you leave, your own
settings come back. On a dedicated server, an admin changes them on the **Mods**
screen, as [Change a mod's settings](/guides/change-mod-settings/) shows.
