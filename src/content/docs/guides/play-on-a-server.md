To join a server that runs mods, install the same enshwick build as the server,
then join as usual. The server checks your mods when you join.

1. Ask the server's owner which enshwick build it runs, or check its Mods screen
   once you are in.
2. [Install enshwick](/guides/install/), or [update it](/guides/update/) to
   match the server.
3. Join the server from the game's menu.

## What the server checks

Some mods change what the server and every player must agree on, such as
recipes. Each mod's page says whether it is one of those.

- If you lack such a mod, or have another version, the game tells you which one
  and you do not join.
- If you have such a mod and the server does not run it, it stays off for that
  visit, and the game tells you so.
- Any other mod is your own business and runs as it is.

## Settings on a server

The server's settings are the ones in force. When you leave, your own come back.
On a dedicated server, an admin changes them on the **Mods** screen, as
[Change a mod's settings](/guides/change-mod-settings/) shows.
