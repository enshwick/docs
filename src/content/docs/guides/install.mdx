Enshwick is the modding API for Enshrouded and the loader that runs its mods.
It goes into the game folder once. Each mod you want
comes after it, from its own archive.

:::caution
Before you install or update, [back up your worlds](/guides/back-up-saves/).
:::

Enshwick does not support another mod loader in the same game folder.
[Compatibility](/reference/compatibility/#does-enshwick-support-another-mod-loader)
says what to do when one is installed.

## Install by hand

<Steps>

1. Download [enshwick.zip](https://github.com/enshwick/enshwick/releases/latest/download/enshwick.zip),
   the newest release.

2. Find the game folder. In Steam, right-click Enshrouded and select
   **Manage**, then **Browse local files**. On a dedicated server, it is the
   folder that holds `enshrouded_server.exe`.

3. Extract the archive into that folder. You now see `powrprof.dll`, its
   signature `powrprof.dll.sig` and a `mods` folder beside the game.

4. On Linux and Steam Deck, add this line to the game's **Launch options** in
   Steam:

   ```text
   WINEDLLOVERRIDES="powrprof=n,b" %command%
   ```

5. Start the game. The main menu shows a **Mods** entry.

</Steps>

If the **Mods** screen shows **Unofficial build**, Enshwick did not find its
signature on your files.
[Is my Enshwick an official build?](/explanation/how-mods-work/#is-my-enshwick-an-official-build)
says what that means for you.

## Add mods

Each mod has its own page under **Mods** in the sidebar, with a **Download**
link to its archive. Extract the archive into the game folder. The mod's file
goes into the `mods` folder, and Enshwick runs it the next time the game
starts.
