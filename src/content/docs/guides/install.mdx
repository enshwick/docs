Enshwick is the modding API for Enshrouded and the loader that runs its mods.
It goes into the game folder once, with Vortex or by hand. Each mod you want
comes after it, from its own archive.

## Install with Vortex

<Steps>

1. Open [Enshwick on Nexus Mods](https://www.nexusmods.com/site/mods/2511).

2. Select **Mod Manager Download**. Vortex puts Enshwick into the game folder.

3. Start the game. The main menu shows a **Mods** entry.

</Steps>

## Install by hand

<Steps>

1. Download [enshwick.zip](https://github.com/enshwick/enshwick/releases/download/dev/enshwick.zip).

2. Find the game folder. In Steam, right-click Enshrouded and select
   **Manage**, then **Browse local files**. On a dedicated server, it is the
   folder that holds `enshrouded_server.exe`.

3. Extract the archive into that folder. You now see `powrprof.dll` and a
   `mods` folder beside the game.

4. On Linux and Steam Deck, add this line to the game's **Launch options** in
   Steam:

   ```text
   WINEDLLOVERRIDES="powrprof=n,b" %command%
   ```

5. Start the game. The main menu shows a **Mods** entry.

</Steps>

The archive is a development build of the newest code. It is the only build
until the first release, 1.0.0.

## Add mods

Each mod has its own page under **Mods** in the sidebar, with a **Download**
link to its archive. Extract the archive into the game folder. The mod's file
goes into the `mods` folder, and Enshwick runs it the next time the game
starts.
