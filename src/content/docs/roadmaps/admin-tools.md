Admin Tools helps the administrators of a server run it.

These are the things I would like Admin Tools to do after Enshwick 1.0. None of
them has a date. Any of them may change.

## Will Admin Tools post to Discord?

I would like Admin Tools to post what happens on the server to a Discord
channel. The posts could cover players who join or leave, announcements, kicks
and bans.

## Can other programs control the server?

I would like Admin Tools to answer requests from other programs over the web,
such as a server panel or a bot. Such a program could read who is online. It
could also run the actions an administrator runs in the game.

## Will the server show its map in a browser?

I would like Admin Tools to serve the world map as a web page. The page could
show where the players are.

## How can you help?

To share an idea for Admin Tools,
[open an issue](https://github.com/enshwick/mods/issues/new/choose) in the mods
repository on GitHub. [What comes next](/aims/) lists the aims for Enshwick
itself.
