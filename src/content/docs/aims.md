---
title: What comes next
description: What the maintainer of Enshwick, the modding framework for Enshrouded, aims to build next. The aims have no dates, and anything may change before 1.0.
type: explanation
---

These are the things I would like Enshwick to do next. None of them has a date.
Until version 1.0, any of them may change.

## Will mods keep working across versions?

From version 1.0, I would like the link between Enshwick and a mod to grow only
by additions. A mod built for an older 1.x version would then keep loading
without a rebuild.

Until 1.0, anything may change between alphas. Back up your saves before you
update.

## Will texts handle numbers in every language?

I plan to add plural forms to mod texts, by the Unicode CLDR rules. A language
gets its own forms for one, a few and many, so a line such as "3 items" reads
right in it.

## Will this site come in more languages?

I would like this site in more languages than English and Ukrainian.

## Will there be mods for one player only?

Mods that run only on one player's game would be nice to have. Today a mod
runs on the server, or on the server and on every player's game. Mods for one
player would need a new look at how those sides work.

## How can you help?

To ask for an API or share an idea,
[open an issue](https://github.com/enshwick/enshwick/issues/new) on GitHub.
Pull requests are welcome too. The
[API coverage](/dev/api-coverage/) page shows what the API reaches today.
